# assets

All art, audio and source packs for **Mera: The Baby Giant**. This folder is part of the game repo (`xenodorian/mera-the-baby-giant`). It used to be a separate private repo mounted as a submodule; since 2026-11-01 it is ordinary files, and large files use Git LFS (`.gitattributes`).

Licences and credits are in `docs/CREDITS.md` and `docs/ASSET_DECISIONS.md`. The owner states they hold full distribution rights to the purchased Merakintsugi Platformer Character Pack (the main character) and publishes it here.

- `_project/icon.png`: the app icon (a Mera frame, from the purchased pack).
- `_previews/`: raw sprite-sheet previews.
- `_source/`: the original zips of each pack.

Not published here: the Android signing key (`_keys/`, gitignored) and the rejected, unused Sprite Kitchen pack (gitignored; its licence forbids redistribution).

Clone: `git lfs install && git clone https://github.com/xenodorian/mera-the-baby-giant.git`
