# mera-assets (PRIVATE)

Licensed art, audio and source packs for **Mera: The Baby Giant** (`xenodorian/mera-the-baby-giant`). The game repo uses this repo as a git submodule at `assets/`.

**Do not make this repo public.** It contains a purchased pack with a custom licence: the Merakintsugi Platformer Character Pack, the main character, which may not be redistributed. The other packs are CC0 or CC-BY 4.0 (see `docs/CREDITS.md` in the game repo), and are kept here too so that all art lives in one place.

- `_project/icon.png`: the app icon (a Mera frame, from the purchased pack).
- `_previews/`: raw sprite-sheet previews, moved out of the public repo.
- Large files use Git LFS (`.gitattributes`).

Clone (owner only): `git clone --recurse-submodules https://github.com/xenodorian/mera-the-baby-giant.git`
